1. 키보드 이벤트 처리

TypeCat은 사용자가 허용한 입력 모니터링 권한으로 수동·수신 전용 글로벌 이벤트 탭을 사용합니다. 키 종류와 이벤트 간 시간을 일시적으로 처리하여 타건음과 캐릭터 반응을 제공합니다. 입력한 문자나 문장을 추출하거나 기록·저장·전송하지 않습니다. 키보드 연결 테스트도 동일한 글로벌 이벤트 탭이 전달받은 실제 키 누름 5회만 세며 입력 내용은 수집하지 않습니다.

2. 설정과 직접 가져온 파일

앱 설정과 사용자가 선택하여 가져온 이미지·음원 사본은 Mac의 로컬 저장소에 보관됩니다. 원본 파일은 수정하지 않습니다. 이미지는 PNG로 다시 인코딩하며, 음원은 가져온 사본과 잘라낸 재생 파일로 보관합니다. 이 파일들은 TypeCat 서버로 업로드되지 않습니다.

3. 수집·공유·추적

앱은 사용자 계정, 광고, 분석, 추적 기능을 사용하지 않습니다. 앱 이용 정보나 개인정보를 TypeCat 서버로 보내지 않으며 광고업체에 판매하거나 공유하지 않습니다. App Store 다운로드, 결제 및 Apple이 제공하는 서비스에는 Apple의 정책이 적용됩니다.

4. 홈페이지와 고객지원

이 홈페이지에는 광고, 분석 스크립트, 문의 입력 폼, 추적 쿠키를 추가하지 않았습니다. 홈페이지를 제공하고 보호하는 과정에서 호스팅 제공업체가 IP 주소·브라우저 정보 등 기술적인 요청 정보를 처리할 수 있습니다. 홈페이지는 GitHub Pages에서 제공합니다. GitHub는 보안 목적으로 방문자의 IP 주소를 기록·보관합니다. 자세한 내용은 GitHub 개인정보처리방침과 GitHub Pages 데이터 수집 안내를 참고하세요.

이메일로 문의하면 이메일 제공업체와 고객지원 메일함이 발신 주소와 사용자가 보낸 메시지를 처리합니다. 문의 내용은 답변 목적으로 사용하며, 문의가 종료된 날로부터 30일 이내에 고객지원 이메일 기록을 삭제합니다. 비밀번호, 입력한 문장, 개인 이미지·음원은 보내지 마세요. 문의 기록 삭제를 원하면 아래의 문의처로 요청할 수 있습니다.

5. 보관·삭제와 권한 철회

가져온 파일은 캐릭터·사운드 편집 화면에서 삭제하거나 교체할 수 있습니다. 앱 삭제만으로 모든 로컬 설정과 파일이 지워지지는 않을 수 있습니다. 필요한 파일을 백업한 뒤 고객지원 페이지의 전체 삭제 절차를 참고하세요. 입력 모니터링 권한은 시스템 설정 → 개인정보 보호 및 보안 → 입력 모니터링에서 언제든 철회할 수 있습니다.

6. 변경 안내와 문의

TypeCat의 운영자는 Eunjin Choi이며, 이 방침을 관리합니다. 데이터 처리 방식이 변경되면 이 페이지와 시행일을 업데이트합니다. 개인정보나 로컬 데이터 관련 문의는 아래의 문의처로 보내주세요.

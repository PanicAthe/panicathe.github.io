TypeCat 시작부터 소리와 친구 설정까지 안내합니다.

키보드 연결 ↗이미지·음원 ↗타이머 ↗파일 관리 ↗

TypeCat은 Mac App Store 출시를 준비하고 있습니다. 공개 버전은 기본 캐릭터 4종과 소리 12종을 제공하며, 앱 내 구입이나 구독은 없습니다.

처음 시작하는 세 단계.

  1. 응용 프로그램에서 TypeCat을 실행한 뒤 메뉴바 아이콘을 누릅니다.
  2. 시스템 설정 → 개인정보 보호 및 보안 → 입력 모니터링에서 TypeCat을 허용합니다.
  3. 환경설정 → 키보드 연결 테스트를 열고 실제 키를 다섯 번 누릅니다. 5/5가 표시되어야 글로벌 입력 전달이 확인된 것입니다.
소리나 캐릭터가 반응하지 않아요.

TypeCat의 상단 스위치가 켜져 있는지, 무음 상태는 아닌지, 소리가 선택되어 있는지 확인하세요. 시스템의 권한 스위치만으로는 실제 입력 전달을 확인할 수 없습니다. 환경설정 → 키보드 연결 테스트에서 실제 키를 다섯 번 눌러 확인하세요. 테스트는 입력한 글자를 읽거나 표시하지 않습니다. 비밀번호 입력 등 보안 입력이 켜진 상황에서는 반응이 제한될 수 있습니다. macOS가 인증이나 재실행을 요구하면 직접 진행해주세요.

내 이미지나 음원도 사용할 수 있나요?

네. 환경설정의 캐릭터·사운드 편집 화면에서 가져올 수 있습니다. 무료 버전에는 직접 만든 캐릭터 1개와 커스텀 사운드 세트 1개를 저장할 수 있습니다. 사운드 세트에는 최대 32개 원본을 가져와 다섯 키 분류에 배정할 수 있습니다. 가져온 사본의 교체나 삭제는 원본 파일을 변경하지 않습니다.

타이머는 어떻게 사용하나요?

메뉴바 또는 환경설정 → 타이머에서 카운트다운이나 뽀모도로를 시작하세요. 캐릭터 아래에 남은 시간이 표시됩니다. 실행 중인 모드나 시간을 변경하려면 먼저 초기화하세요. TypeCat을 끄면 타이머가 일시정지되며 다시 켠 뒤 이어서 시작할 수 있습니다. 앱을 닫았다 열어도 저장된 남은 시간부터 이어서 시작할 수 있습니다. 앱이 닫힌 동안에는 카운트다운하지 않습니다.

소리를 비교하거나 볼륨을 바꾸고 싶어요.

목록의 미리듣기 버튼으로 현재 선택을 바꾸지 않고 다른 소리를 들어보세요. 키보드·효과음·악기별로 탐색하고 자주 쓰는 소리는 즐겨찾기에 담을 수 있습니다. 메뉴바와 사운드 설정에서 앱 볼륨과 무음을 조절합니다. 타이머 완료 알림은 별도 볼륨을 사용합니다.

설정과 가져온 파일을 모두 지우려면요?

필요한 이미지·음원을 먼저 백업한 뒤 TypeCat을 종료하세요. Mac App Store 버전은 Finder → 이동 → 폴더로 이동에서 ~/Library/Containers/app.squishkey.mac/을 확인합니다. TypeCat 데이터가 맞는지 확인한 뒤 휴지통으로 보내면 앱 설정과 가져온 사본이 삭제됩니다. 앱만 제거하면 이 데이터가 남을 수 있습니다. 이전 개발 버전은 ~/Library/Application Support/app.squishkey.mac/와 해당 환경설정 도메인에 별도 데이터가 남을 수 있습니다. 다른 앱의 폴더는 삭제하지 마세요.

제가 입력한 문장을 기록하나요?

아니요. 키 종류와 이벤트 간 시간은 소리와 애니메이션을 위해 Mac 안에서만 일시적으로 처리됩니다. 입력한 문자나 문장은 추출·기록·저장·전송하지 않습니다. 자세한 내용은 개인정보처리방침을 확인하세요.
